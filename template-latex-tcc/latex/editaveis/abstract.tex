\begin{resumo}[Abstract]
 \begin{otherlanguage*}{english}
   Software product quality is a key factor for maintainability and for reducing costs 
   throughout the lifecycle. In this context, models such as ISO/IEC 25010 highlight 
   maintainability and its subcharacteristics, while code smells are understood as signs 
   of design and implementation problems associated with the degradation of internal 
   quality. Traditional static analysis tools, such as SonarQube, are widely used to detect 
   these anomalies, but they present limitations related to fixed metric thresholds and 
   false positives. In parallel, Artificial Intelligence (AI)-based approaches, especially 
   Large Language Models (LLMs), have shown potential to capture more complex structural 
   and semantic patterns.

   This work empirically investigates how AI-based systems and static analysis tools support 
   software quality assurance in detecting code smells. To this end, a structured literature 
   review was conducted, adapted from a systematic review protocol, which identified 42 
   relevant studies published between 2022 and 2025. Then, a controlled experiment was 
   planned and executed with seven treatments: SonarQube, ChatGPT, Claude, and DeepSeek in 
   zero-shot and few-shot versions, using the manually annotated MLCQ dataset as reference.

   The results showed statistically significant differences between the treatments, indicating 
   distinct behaviors in code smell detection. Overall, SonarQube achieved higher global 
   accuracy and behaved more conservatively, while LLMs showed greater sensitivity to detect 
   possible anomalies, suggesting that AI-based approaches can complement traditional tools 
   and broaden the coverage of code quality analysis.

   \noindent 
   \textbf{Key-words}: software engineering. artificial intelligence. code smells. software quality. language models. static analysis.
 \end{otherlanguage*}
\end{resumo}
